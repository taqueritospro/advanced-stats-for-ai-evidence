# Stats for AI B2

Modelo de regresión múltiple para explicar el apalancamiento financiero
((shortdebt + longdebt) / totalassets) de empresas públicas de EE. UU. con datos de 2024.

## Cómo ejecutarlo
1. Crear el entorno: `python3 -m venv .venv` y `source .venv/bin/activate`
2. Instalar librerías: `pip install -r requirements.txt`
3. Colocar `usfindata.csv` y `usfirms.csv` (disponibles en Canvas) dentro de `data/`
4. Abrir `apalancamiento.ipynb` en VS Code y seleccionar el kernel `.venv`

Los datos no se incluyen en el repositorio.
